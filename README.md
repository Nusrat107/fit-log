## 📖 About The Project

**FitLog** is a modern workout library designed to make exercise discovery and daily workout planning simple and organized.

Users can explore different workouts, view detailed exercise information, create a personalized daily workout plan, save workouts for later, and mark completed exercises as **Done**.

The application is built with a strong focus on **responsive design, reusable components, clean UI, and a smooth user experience**.

---

## 🚀 Technologies Used

| Technology               | Purpose                                      |
| ------------------------ | -------------------------------------------- |
| **Next.js**              | React framework for building the application |
| **React.js**             | Component-based UI development               |
| **JavaScript (ES6+)**    | Application logic and functionality          |
| **Tailwind CSS**         | Responsive and modern styling                |
| **React Context API**    | Global state management                      |
| **Lucide React**         | Modern and lightweight icons                 |
| **REST API / Fetch API** | Fetching workout data                        |
| **Next.js Image**        | Optimized image loading                      |

## ✨ Key Features

### 🏋️ Workout Library

Explore a collection of workouts with useful information including:

* ⏱️ Workout duration
* 🔥 Estimated calories
* 📈 Difficulty level
* ⭐ Workout rating
* 🏋️ Required equipment
* 💪 Target muscle groups

---

### 🔍 Workout Details

View detailed information about individual workouts.

Each workout includes:

* Workout description
* Exercise instructions
* Duration
* Calories
* Difficulty
* Rating
* Equipment
* Target muscle groups

---

### 📋 Personalized Today's Plan

Create a personalized daily workout routine.

Users can:

* Add workouts to **Today's Plan**
* Remove workouts from the plan
* Manage their daily routine
* Add up to **5 exercises** to the plan

---

### 💾 Save Workouts

Save interesting workouts and access them later.

Users can easily manage their saved workouts without having to search for the same exercise again.

---

### ✅ Workout Tracking

Track workout completion by marking planned exercises as **Done**.

Toast notifications provide instant feedback whenever users perform important actions.

---

### 📊 Smart Workout Sorting

Easily organize workouts using different sorting options:

* ⏱️ Duration
* 🔥 Calories
* ⭐ Rating

This makes it easier to find workouts based on the user's needs.

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project folder:

```bash
cd fitlog
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the application in your browser:

```text
http://localhost:3000
```
